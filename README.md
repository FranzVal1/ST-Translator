# SillyTavern Safe Translation

Расширение двустороннего перевода для SillyTavern 1.18.0+.
Google, Yandex и Bing используются через штатные серверные маршруты SillyTavern.

## Установка

В **Extensions → Install extension** укажите:

```
https://github.com/FranzVal1/ST-Translator
```

После установки/обновления перезагрузите страницу. Для ручной установки поместите файлы расширения в `data/<пользователь>/extensions/ST-Translator`.
Зависимости npm нужны **только для разработки и тестирования**, не для использования расширения.

**Отключите автоматические режимы встроенного Chat Translation.** Одновременная работа двух автопереводчиков не поддерживается. При конфликте исходящего автоперевода генерация блокируется с предупреждением.

## Как пользоваться

Откройте **Extensions → Safe Translation**:

- **Автоперевод ответов персонажа** — показывает перевод, не меняя `message.mes`.
- **Язык отображения ответов** — по умолчанию русский.
- **Переводить реплики игрока для LLM** — отдельная опция, **по умолчанию выключена**.
- **Язык реплик игрока для LLM** — по умолчанию английский.

### Реплики игрока

Вы пишете по-русски. Перед генерацией штатный `generate_interceptor` заменяет текст реплик игрока **только в копии контекста для модели**. В сохранённом чате и редакторе остаётся русский оригинал. Сохранённый перевод повторно используется на следующих ходах, в том числе после перезагрузки; изменение исходника, языка, провайдера, правил защиты или prompt-only преобразований делает его неактуальным.

При первом включении переводятся также предыдущие реплики игрока, переданные SillyTavern перехватчику. Это может занять время и передаёт их переводимый текст внешнему сервису. Системные сообщения и реплики, начинающиеся со slash-команд, пропускаются. Текст карточки персонажа и системные промпты эта опция не переводит.

При ошибке доступны **«Повторить»**, **«Отправить оригинал»** (только для этой генерации) и **«Отмена»**. Молчаливой отправки оригинала при ошибке нет. Сообщение игрока к этому моменту уже добавлено в локальный чат: отменяется генерация ответа, а не сохранение реплики.

Кнопка 🌐 в меню сообщения переключает оригинал и сохранённый перевод без сетевого запроса. У реплики игрока английская версия появляется после подготовки контекста для генерации. Текст для модели и безопасная HTML-версия для отображения сериализуются отдельно.

### Перевод всего чата

**«Перевести ответы в чате»** обрабатывает ответы персонажей последовательно. Есть прогресс, остановка и повтор только ошибок. Повторный параллельный запуск блокируется. При смене чата, изменении настроек и очистке переводов текущие задания отменяются. Уже обработанные сообщения сохраняются при завершении/остановке в том же чате.

**«Удалить переводы»** удаляет данные этого расширения, но не оригиналы и не чужой `display_text`. **«Очистить кэш»** очищает только ограниченный кэш в памяти; сохранённые переводы сообщений остаются.

## Защита содержимого

Переводчику отправляются текстовые сегменты, а защищённые участки собираются локально из исходных байтов:

- служебные блоки вроде `<instruction>...</instruction>` при включённой защите;
- HTML-комментарии, скрипты, стили, `pre`, `code`, `textarea`, `template`, SVG/Math;
- макросы `{{...}}`, включая вложенные; незавершённый макрос защищается до конца сообщения;
- URL и поддерживаемые Markdown-изображения;
- элементы с `hidden`, явными `display:none`, `visibility:hidden/collapse`, `content-visibility:hidden`;
- дополнительно указанные теги и CSS-классы — целиком, включая атрибуты и потомков.

**HTML — не синоним скрытой инструкции:** `<b>Hello</b>` переводится, `<instruction>Secret</instruction>` — нет. Русская инструкция внутри защищённого блока останется русской и в контексте LLM.

Перевод `title`, `alt`, `placeholder`, `aria-label` включается отдельно. Макросы, URL и HTML-сущности внутри значений остаются локальными; перевод экранируется, поэтому кавычка из ответа сервиса не создаёт новый атрибут. Атрибуты защищённых блоков не переводятся.

### Ограничения защиты

Это консервативный текстовый парсер, **не HTML-санитайзер и не вычислитель CSS**. Внешние стили, селекторы по ID, наследование CSS и произвольную браузерную разметку он не моделирует. Для карточек со скрытыми инструкциями задавайте явные защищённые теги/классы. Неоднозначные encoded/escaped inline-стили сохраняются целиком, что иногда оставляет видимый текст непереведённым. Незакрытый служебный блок также защищается до конца сообщения.

Одинарные backticks сохраняют прежнюю ролевую семантику: `` `внутренняя речь` `` переводится; два и более backticks защищают содержимое как код. Полный разбор Markdown (например, всех вариантов относительных ссылок и таблиц) не реализован.

Расширение не может гарантировать сохранность после преобразований **других** расширений: исходящий перехватчик получает текст уже после prompt-only regex/file processing SillyTavern. Результат, который не проходит внутреннюю сборку, не заменяет оригинал.

## Архитектура

- `parser.js` — защищённые токены, вложенные планы атрибутов, безопасная сборка.
- `translation.js` — целые сегменты в пакетах, уникальные маркеры с ID, проверка порядка/количества; при повреждении повторяются только сегменты неудачного пакета. Длинный сегмент режется без разрыва UTF-16 surrogate pairs.
- `provider.js` — Google/Bing `{text, lang}`, Yandex `{chunks: [text], lang}`; тайм-аут на запрос, отмена, повторы временных ошибок и `Retry-After`; ограниченный LRU-кэш.
- `runtime.js` — задания, защита от устаревших результатов и смены чата, очередь, копии промпта, владение отображаемым текстом.
- `index.js` — настройки, кнопки, редактор и события SillyTavern.

Лимиты пакетов: Google/Yandex — 5000 UTF-16 code units, Bing — 1000. Скорость зависит от провайдера и того, сохраняет ли он маркеры; фиксированного обещания ускорения нет. Диагностика не выводит текст переписки или тело ответа API в консоль расширения. Сам сервер SillyTavern и провайдер могут вести свои журналы.

## Проверки для разработчика

```sh
npm ci --include=dev
npm test
npm run check
```

CI запускает автономные Node/DOM-тесты на Node 22 и 24, без внешних API. Есть регрессии для скрытых блоков, атрибутов, повреждённых маркеров, границ лимитов, отмены, ошибок, очереди, смены чата, свайпов, редактирования и сохранности чужого отображения.

Дополнительный opt-in тест с настоящим SillyTavern и Google (отправляет синтетические фразы внешнему сервису):

```sh
npx playwright install chromium
# Установите текущее рабочее дерево расширения в отдельный тестовый SillyTavern.
ST_URL=http://127.0.0.1:18765 npx playwright test tests/live-st.spec.mjs --reporter=line
```

Браузерная проверка проведена на SillyTavern 1.19.0 (`06bde939`). Проверяется реальная загрузка manifest hook и нативный вызов перехватчика, а не ответ платной LLM. Live-проверка всех внешних провайдеров не входит в автономные тесты.
